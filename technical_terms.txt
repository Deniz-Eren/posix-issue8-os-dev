# technical_terms.txt — project-specific technical nouns and technical verbs
# accepted during Simplified Technical English checks.
#
# The subject field of this repository is operating system development targeting
# POSIX.1-2024 (IEEE Std 1003.1-2024 / ISO/IEC/IEEE 9945:2026). Domain terms
# from computer science, systems, documentation, and general engineering are
# recorded here so a Simplified Technical English checker accepts them when
# present.
#
# Format: one term on each line. Everything after '#' is a comment.

feature          # a function or property of a standard or product
